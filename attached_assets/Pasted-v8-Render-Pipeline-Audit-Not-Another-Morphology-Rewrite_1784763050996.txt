Do not create another chassis system.
The live screenshots still show the same organic morphology despite repeated rewrites claiming to replace it.
This means the primary problem is now likely one of:
1. drawVirus() is still calling legacy morphology code
2. the new chassis renderer is not used by actual Enemy instances
3. a second rendering pass is drawing legacy lobes over the chassis

5. cached/duplicate files exist and the edited file is not the imported file
